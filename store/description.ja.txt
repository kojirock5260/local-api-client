Local API Client は、Chrome のサイドパネルで動く localhost 専用のミニマルな REST クライアントです。

開発中のサーバーに、タブを離れずにリクエストを送れます。メソッドを選び、ポートとパスを打ち、ヘッダーと本文を付けて送ると、レスポンスが折りたためる JSON ツリーで表示されます。アカウントもクラウドも計測もありません。入力した内容はすべて、お使いのマシンの chrome.storage.local に留まります。

できること
・GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS と任意のヘッダー
・本文はキーと値の行（JSON として送信）、フォーム（x-www-form-urlencoded）、生テキストのいずれか
・レスポンスは届いた分から順に表示。SSE や長い応答もそのまま見られ、Cancel しても途中まで届いた内容は残ります
・JSON ツリーと生テキストの切り替え、レスポンスヘッダー、実際に送った内容の控え
・ドキュメントや DevTools、AI が出した curl コマンドを貼ると、そのままリクエストになります。逆に curl としてコピーもできます
・Bearer / Basic の Authorization ヘッダーを一クリックで設定。Chrome が持つ localhost の Cookie を送るかどうかも選べます（既定はオフ）
・直近 30 件の履歴をレスポンスごと保持。保存したリクエストはグループ分けでき、JSON ファイルで書き出しと取り込みができます
・パネルのどこからでも Cmd/Ctrl+Enter で送信。Download でレスポンス本文を受信したままの形で保存できます

なぜ localhost 専用なのか
Web 版の API クライアントはプロキシやエージェント無しでは localhost に届かず、デスクトップ版の多くはアカウントとクラウド同期が前提です。この拡張機能が Chrome に求める権限は sidePanel と storage の 2 つと、localhost / 127.0.0.1 へのアクセスだけです。開発者にも第三者にも一切接続しません。それ以外のホストへのリクエストは、送信前に拒否されます。

プライバシー
収集も送信もしません。解析、クラッシュレポート、クラウド同期、リモートコードはありません。ソースコードは GitHub で公開しています: https://github.com/kojirock5260/local-api-client

Chrome 114 以上が必要です。
